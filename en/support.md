# SeiriBox Support

Questions, bug reports and requests are welcome by email.

## Contact

**Email: yumsaki@gol.com**

Replies usually take a few days. For bug reports, the following helps a lot:

- Your Mac model and macOS version
- Which features (cards) were switched on
- What you were doing when it happened

## Requirements

- macOS 14.0 or later
- Apple silicon and Intel

## FAQ

### Can I undo something that was moved by mistake?

Yes. Open “Show History” at the bottom right of the window. Actions are listed
newest first, and you can undo a single item or a whole day at once.

### Can a file be deleted permanently?

No. Whenever SeiriBox “removes” something, it goes to the Trash.
It stays there until you empty the Trash.

### What happens if a file with the same name already exists?

It is never overwritten. The moved file is placed next to it with a number added,
like “Name 2.pdf”.

### I was asked to choose a folder

This appears the first time you switch on a feature that works on your Desktop,
Pictures, Movies or Music folder. Only the folder you choose is used; nothing
else is read. You are asked once per folder (for example, the two Pictures
features share one choice).

### It says access is not allowed

**Downloads folder:** open System Settings → Privacy & Security → Files and Folders,
turn on “Downloads Folder” for SeiriBox, then try again.

**Desktop, Pictures, Movies, Music:** follow the prompt and choose the folder again.
You will also need to choose again if you moved or renamed the folder.

### I closed the window and it disappeared from the Dock

SeiriBox hasn’t quit. Open it from the box icon in the menu bar.
You can also quit from that menu.

### Does it show the window every time I log in?

No. When it opens at login, the window stays hidden and SeiriBox waits quietly
in the menu bar. Open it from the menu bar icon when you need it.

### Is automatic unzipping safe?

Archives are inspected before they are expanded. Anything that would expand
enormously (a “zip bomb”) or that tries to write outside its folder is not
unzipped automatically. Expanded files keep their download information
(quarantine), so macOS still shows its usual warnings.

### My folders are named in Japanese (画像, 書類 …)

If you used SeiriBox in Japanese before switching your Mac to English, it keeps
using the folders you already have instead of creating English-named copies,
so nothing gets split across two folders.

### Does deleting the app remove its history?

Because of how macOS works, dragging the app to the Trash leaves its data folder
behind. See the [Privacy Policy]({{ site.baseurl }}/en/privacy/) for how to remove it completely.
