# SeiriBox

A macOS app that tidies your Desktop and Downloads folder automatically.

Pick what you want done and switch it on. There are no settings.
From then on, new files are tidied as they arrive.

**File contents and names never leave your Mac.**

## Built to be safe

### Nothing is deleted

SeiriBox never deletes a file permanently. Anything it removes goes to the Trash.
If a file with the same name already exists, it is never overwritten — a number is added instead.

### You see what will happen before it happens

When you switch a feature on, SeiriBox first shows a list of exactly which files
would be moved. You confirm before anything runs.

### Everything can be undone

Every action is recorded. From “Show History” at the bottom of the window,
you can undo a single item or a whole day at once.

## What it can do

- Sort your Desktop and Downloads by kind
- Move screenshots into their own folder
- Unzip archives automatically (hostile archives are refused)
- Move videos to Movies and music to Music
- Sort photos into folders by date
- Find byte-for-byte duplicate files and move them to the Trash
- Trash installers (dmg / pkg) older than 30 days
- Remove empty folders

18 features in total. SeiriBox lives in your menu bar and can open at login.

## Requirements

macOS 14.0 or later. Apple silicon and Intel.
